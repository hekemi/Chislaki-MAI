# Калькулятор численных методов

В проекте есть веб-интерфейс и сервер на Go. Запустить можно двумя способами: из исходников или через Docker прямо из GitHub.

## 1. Запуск из исходников

Должен быть установлен Go 1.22+.

```bash
git clone https://github.com/hekemi/Chislaki-MAI.git
cd Chislaki-MAI
go run ./cmd/server
```

После запуска в браузере открываем

http://localhost:8080

## 2. Запуск через Docker из GitHub

Запуск без локальной сборки проекта.

```bash
docker build -t chislaki-mai https://github.com/hekemi/Chislaki-MAI.git#govers
docker run --rm -p 8080:8080 chislaki-mai
```

После запуска в браузере открываем

http://localhost:8080

- Задание 1 — решение СЛАУ методом Гаусса и методом простой итерации.
- Задание 2 — решение трёхдиагональной СЛАУ методом прогонки и методом Зейделя.
- Задание 3 — делать его не требовалось.
- Задание 4 — решение нелинейного уравнения методами бисекции, простой итерации и Ньютона.
- Задание 5 — интерполяция по узлам методами Лагранжа и Ньютона.
- Задание 6 — кубический сплайн с выбором краевых условий.
- Задание 7 — аппроксимация методом наименьших квадратов: линейная и квадратичная модели.
- Задание 8 — вычисление первой и второй производных по таблице значений.
- Задание 9 — численное интегрирование методом Симпсона.
- Задание 10 — решение задачи Коши методами Рунге-Кутты 4 и Адамса.
- Задание 11 — краевая задача для ОДУ второго порядка методом прогонки.

Во всех заданиях можно поменять значения и посмотреть, как меняются результаты.
