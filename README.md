# Калькулятор численных методов

Это стартовый каркас проекта с:

- Go-бэкендом;
- графической фронтенд-оболочкой;
- левой панелью выбора из 11 заданий;
- отдельным модулем на каждое задание;
- API, через которое фронтенд получает данные от Go.

## Структура проекта

- `cmd/server` — запуск HTTP-сервера.
- `internal/tasks/task01` ... `task11` — отдельные модули для заданий.
- `web` — фронтенд: HTML, CSS и JavaScript.

## Как запустить

1. Установи Go 1.22 или новее.
2. Открой терминал в корне проекта.
3. Запусти сервер командой:

   `go run ./cmd/server`

4. Открой в браузере:

   `http://localhost:8080`

## Как дальше работать

### 1. Пишешь логику по модулям

Для каждого задания уже есть отдельный пакет:

- `internal/tasks/task01`
- `internal/tasks/task02`
- ...
- `internal/tasks/task11`

Внутри каждого пакета можно хранить:

- функции вычислений;
- структуры для входных данных;
- функции проверки ошибок;
- генерацию ответа для фронтенда.

### 2. Подключаешь модуль к API

Сейчас API отдает только метаданные задания.
Когда напишешь алгоритм, добавь в пакет новые функции и вызови их из `cmd/server/main.go`.

### 3. Расширяешь фронтенд

Файл `web/app.js` уже получает задания из Go-сервера.
Позже ты можешь добавить:

- формы ввода;
- таблицы результатов;
- графики;
- кнопки расчета;
- экспорт в файл.

### 4. Добавляешь новые поля

Если для задания нужны входные параметры, просто расширяй структуру `internal/tasks.Meta`.
Фронтенд автоматически сможет прочитать новые поля через JSON.

## Что уже готово

- левая панель из 11 заданий;
- переключение между заданиями;
- связь фронтенда с Go через `fetch('/api/tasks')`;
- отдельные пакеты для каждого задания;
- базовая современная оболочка.

## Что тебе нужно сделать следующим шагом

1. Выбрать первый метод.
2. Вписать алгоритм в `task01`.
3. Добавить endpoint для запуска вычислений.
4. Подключить форму ввода на фронтенде.
