# Калькулятор численных методов

Это стартовый каркас проекта с:

- Go-бэкендом;
- графической фронтенд-оболочкой;
- левой панелью выбора из 11 заданий;
- отдельным модулем на каждое задание;
- API, через которое фронтенд получает данные от Go.

## Структура проекта

- `cmd/server` — запуск HTTP-сервера.
- `internal/tasks/task01` ... `task11` — отдельные модули для заданий.
- `web` — фронтенд: HTML, CSS и JavaScript.

## Как запустить

1. Установи Go 1.22 или новее.
2. Открой терминал в корне проекта.
3. Запусти сервер командой:

   `go run ./cmd/server`

4. Открой в браузере:

   `http://localhost:8080`
