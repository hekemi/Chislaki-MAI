Запуск из GitHub

- Клонировать репозиторий:

```powershell
git clone <repo_url>
cd Chislennie_metodi
```

- Собрать и запустить сервер (PowerShell):

```powershell
go build ./cmd/server
# или сразу запустить
go run ./cmd/server
# если собрали с -o: .\bin\server.exe
```

- Открыть в браузере: http://localhost:8080

- Запуск тестов:

```powershell
go test ./...            # все тесты
go test ./internal/tasks/task06 -v   # тесты сплайна (пример)
```

- Если порт 8080 занят (Windows):

```powershell
netstat -ano | findstr :8080
Stop-Process -Id <PID> -Force
```

Краткое описание заданий и реализаций

- **Задание 1**: решение СЛАУ. Реализованы метод Гаусса (с шагами) и итерационный метод (Жакоби/Зейдель-стиль) с записью итераций и невязок.

- **Задание 2**: трёхдиагональная система. Реализован метод прогонки (алгоритм Томаса) и итерационный метод Зейделя; возвращаются решения, невязки и итерационные таблицы.

- **Задание 3**: заготовка/плейсхолдер — предусмотрена текстовая область в интерфейсе для свободной заметки; серверная часть — заглушка (нет численного алгоритма).

- **Задание 4**: решение нелинейного уравнения. Парсер выражений и три метода: бисекция, простая итерация (с простым преобразованием) и метод Ньютона; возвращаются шаги и критерии сходимости.

- **Задание 5**: интерполяция по узлам из CSV. Реализованы многочлен Лагранжа и формула Ньютона (разностная форма), вычисление значения в точке и оценка погрешности.

- **Задание 6**: кубический сплайн. Построение сплайна с возможностью натуральных или заданных значений вторых производных на концах; оценка в точках, возвращение коэффициентов сегментов. Есть unit-тесты для проверки граничных условий.

- **Задание 7**: метод наименьших квадратов. Аппроксимация линейной и квадратичной моделей (обычные нормальные уравнения), расчёт SSE/RMSE и таблица наблюдений; поддерживается ввод своих точек (JSON).

- **Задание 8**: похож на 6, но возвращает значения сплайна и его производных S', S'' в заданных точках.

- **Задание 9**: численное интегрирование композитной формулой Симпсона с удвоением числа разбиений; возвращаются итерации и оценка погрешности по правилу Симпсона.

- **Задание 10**: решение ODE y'=f(x,y). Реализован явный RK4 и предиктор-корректор Адамс (Adams–Bashforth/Adams–Moulton) с начальным шагом от RK4.

- **Задание 11**: краевая задача для ОДУ второго порядка. Дискретизация центральными разностями, построение трёхдиагональной системы и решение методом прогонки; учтены общие линейные краевые условия.

Примечания

- Статические файлы интерфейса находятся в `web/`.
- Сервер монтирует REST-эндпойнты по шаблону `/api/task<N>/solve` — см. `cmd/server/main.go`.
- Быстрый прогон локально: запустите `go run ./cmd/server` и откройте `http://localhost:8080`.

Запуск без клонирования (с GitHub)

- Сборка образа прямо из репозитория на GitHub (замените `<owner>/<repo>` и ветку при необходимости):

```bash
docker build -t chislennie-metodi:latest https://github.com/<owner>/<repo>.git#main
```

- Запуск собранного образа:

```bash
docker run --rm -p 8080:8080 chislennie-metodi:latest
```

- Альтернатива: запустить контейнер с временным клоном и без сохранения файлов локально (быстрый запуск):

```bash
docker run --rm -it -p 8080:8080 golang:1.22-alpine sh -c "apk add --no-cache git && git clone https://github.com/<owner>/<repo>.git app && cd app && go run ./cmd/server"
```

В обоих вариантах сервер будет доступен по `http://localhost:8080`.
